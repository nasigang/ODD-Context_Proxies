# 08. Canonical Machine-Readable Evidence Data

This directory houses all locked, authoritative CSV data tables supporting the paper findings.

## Data Files
- `TABLE1_NESTED_MODELS_V6.csv`: Primary nested model AP, AUROC, Brier, $\Delta\text{AP}$, and 95% CIs.
- `TABLE2_THRESHOLD_SENSITIVITY_V6.csv`: Collision horizon sensitivity ($	au=2.0, 3.0, 5.0$ s).
- `TABLE3_FEATURE_CONFIRMATION_V6.csv`: 13-feature holdout confirmation (10/13 confirmed, 13/13 sign concordant).
- `TABLE4_REPAIRED_SCENARIO_EFFECTS_V6.csv`: Complete 17-feature scenario-level temporal matrix across Peak, AUC, and TET3.
- `KPI_CONSTRUCT_VALIDITY_V6.csv`: Supportive within-dataset vehicle-response KPI correlations.
- `TEMPORAL_DOWNSAMPLING_EVIDENCE_V6.csv`: Sampling rate sensitivity evidence.
- `CLAIM_EVIDENCE_LEDGER.csv`: Comprehensive trace linking every claim in the paper to supporting data.
- `BIBLIOGRAPHY_PROVENANCE.csv`: Primary-source verified metadata for all 16 cited references.
